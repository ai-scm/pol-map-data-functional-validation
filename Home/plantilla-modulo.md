# Nombre del módulo

Plantilla base para documentar un módulo de la aplicación. Copiar este archivo como `README.md` dentro de `Home/<numero>_<nombre-modulo>/` (el número corresponde al orden del menú) y completar los campos.

## 1. Identificación

| Campo | Valor |
|---|---|
| Módulo | Nombre visible en el menú |
| Ruta de acceso | `Menú principal > Módulo` |
| Estado de documentación | Faltante / En progreso / Verificación / Terminado |
| Responsable | Nombre o equipo |
| Fecha de actualización | AAAA-MM-DD |

## 2. Descripción

Explicación corta del propósito del módulo y de la información o funcionalidad que ofrece dentro de la aplicación.

## 3. Submódulos

Listado de los submódulos u opciones disponibles dentro del módulo.

## 4. Estados de documentación

| Estado | Descripción |
|---|---|
| `Faltante` | La documentación aún no se ha iniciado. |
| `En progreso` | La documentación se está redactando. |
| `Verificación` | La documentación está redactada y pendiente de revisión. |
| `Terminado` | La documentación está completa y verificada. |
