# 02. Certificaciones AWS

## 1. Identificación

| Campo | Valor |
|---|---|
| Orden en el menú | 02 |
| Módulo | Certificaciones AWS |
| Ruta de acceso | `Menú principal > Certificaciones AWS` |
| Estado de documentación | Faltante |
| Responsable | Pendiente por confirmar |
| Fecha de actualización | Pendiente por confirmar |

## 2. Descripción

Módulo que agrupa los tableros o recursos asociados a las certificaciones AWS, organizados por familia de certificación y nivel.

## 3. Submódulos

- Cloud Practitioner 1 a 5
- AI Practitioner 1 a 4
- Solutions Architect 1 a 5
- Data Engineer 1 a 4
- Developer Associate 1 a 6

## 4. Estados de documentación

| Estado | Descripción |
|---|---|
| `Faltante` | La documentación aún no se ha iniciado. |
| `En progreso` | La documentación se está redactando. |
| `Verificación` | La documentación está redactada y pendiente de revisión. |
| `Terminado` | La documentación está completa y verificada. |
