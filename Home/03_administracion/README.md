# 03. Administración

## 1. Identificación

| Campo | Valor |
|---|---|
| Orden en el menú | 03 |
| Módulo | Administración |
| Ruta de acceso | `Menú principal > Administración` |
| Estado de documentación | Faltante |
| Responsable | Pendiente por confirmar |
| Fecha de actualización | Pendiente por confirmar |

## 2. Descripción

Módulo de administración de la plataforma: gestión de menús, imágenes, apariencia, control de accesos y usuarios.

## 3. Submódulos

- Asignación Menus
- Configuracion de imagenes
- Configuracion paleta de colores
- Control Menus
- IAM
- Agregar Usuarios
- Orquestador de Bots

## 4. Estados de documentación

| Estado | Descripción |
|---|---|
| `Faltante` | La documentación aún no se ha iniciado. |
| `En progreso` | La documentación se está redactando. |
| `Verificación` | La documentación está redactada y pendiente de revisión. |
| `Terminado` | La documentación está completa y verificada. |
