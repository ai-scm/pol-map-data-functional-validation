# 14. Planta Nacional

## 1. Identificación

| Campo | Valor |
|---|---|
| Orden en el menú | 14 |
| Módulo | Planta Nacional |
| Ruta de acceso | `Menú principal > Planta Nacional` |
| Estado de documentación | Faltante |
| Responsable | Pendiente por confirmar |
| Fecha de actualización | Pendiente por confirmar |

## 2. Descripción

Módulo de gestión y análisis de llamadas de la planta nacional, con reportes nacionales y regionales, control de ocupación y audios de telefonía, incluyendo vistas por unidad (MEBUC, MEBOG).

## 3. Submódulos

- 01. Reporte Nacional Llamadas de Emergencia
- 02. Reporte Regional Llamadas
- 03. Gestión y Análisis de Llamadas por Turno
- 04. Identificación Automática de Ubicación (ALI)
- 05. Audios Telefonía
- 06. Control de llamadas pérdidas y contestadas
- 07. Comparativo Llamadas por Rango de Fechas
- Audios Telefonía - MEBUC
- Control de Ocupación - MEBUC
- Rendimiento y Gestión de Llamadas - MEBUC
- Reporte Regional Llamadas - MEBOG
- Reporte Regional Llamadas - MEBUC
- Formulario Carga Reporte Webex

## 4. Estados de documentación

| Estado | Descripción |
|---|---|
| `Faltante` | La documentación aún no se ha iniciado. |
| `En progreso` | La documentación se está redactando. |
| `Verificación` | La documentación está redactada y pendiente de revisión. |
| `Terminado` | La documentación está completa y verificada. |
